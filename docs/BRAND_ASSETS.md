# Brand assets

## Open Focus wordmark

The product wordmark is set as live text ("Open Focus") using a custom typographic treatment. It is intentionally not a separate illustrated logo. The small website/app-preview icon uses an "OF" typographic monogram so the wordmark remains the primary identity.

## Third-party app marks

The browser preview uses SVG marks from the Simple Icons project for the apps shown in its scanner and app list:

- Instagram
- Snapchat
- YouTube
- Facebook
- TikTok
- X
- Reddit
- Discord
- Netflix
- Pinterest

Source: https://github.com/simple-icons/simple-icons

Simple Icons assets are distributed under CC0-1.0. Product names and marks remain the property of their respective owners. These marks are used only to identify apps that a user may choose to manage; this project is independent and is not affiliated with or endorsed by those services.

## Android app icons

The native Android app does not substitute generic letter badges for installed apps. It asks Android's PackageManager for each installed launcher's actual application icon and renders that icon locally on the device. The icon is not uploaded.
